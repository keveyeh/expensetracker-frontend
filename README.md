# Expense Tracker (React)
# website link

## Features
- Add, edit and delete transactions.
- Search and filter transactions.
- Budget management by category.
- Charts for income and expenses.
- Currency switch (FCFA, USD, EUR).
- local storage support.
  ## Tech Stack
  - React
  - JavaScript (ES6)
  - CSS Modules
  - Context API
  - Chart.js
